# machine-learning-image-analysis

## Overview
This basic machine learning model analyzes and determines whether or not an uploaded image contains a dog or not.

## Objective
The objective of this project was to build a technical foundation and understand the fundamental principles that govern machine learning models.

## Results
The model performed relatively well, though errors were notices in its final performance. The model was trained on over 20,000 publicly available images.

## What I Learned
Most basic machine learning models follow the same pattern: importing tools, implementation of the model, training on data sets, and results. The most important thing I learned was how crucial good quality data is for the performance of a model. If a model is fed suboptimal data, no matter how much training it undergoes, it will perform at a suboptimal level.

## Future Projects
I would love to explore this concept applied to real-world issues, such as being used for detecting abnormalities in medical imaging.
